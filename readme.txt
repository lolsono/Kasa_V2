une fois avoir installé les packages JSON avec : npm installé
On peut lancer les différents services.

pour lancer le front end : npm run dev
pour lancer le backend : npm start

Pour lancer les test unitaire :
Il faut taper : npm test
On utilise le framework JEST. Et tous les tests sont dans le fichier __test__.
Nous testons uniquement le système de favoris ainsi que la partie carrousels de la page détails des logements.
